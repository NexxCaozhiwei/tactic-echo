# 0.2.0 首轮短实测

本轮验证HUD、双练习配置和事件收据；自动切换、动态推荐及真实TEK释放未开放。只启用TEF信号源，TE不同时运行。

## A. 加载、单体及菜单

1. `/reload`，确认聊天提示v0.2.0、默认暂停，新HUD有大图标、随后两步、状态行。
2. `/tef single`，循环关闭，主动开始。顺序为116→205→205→143。
3. 按对应精确等级手动施法；两次205需两次独立施法。143读条取消一次，步骤保持；再正常完成，显示完成。
4. `/tef settings`检查六页；在推荐配置编辑框输入但不保存，施法/事件刷新及页面返回不得覆盖草稿。只有点击保存才应用，应用后暂停、首步。
5. HUD外观检查缩放、锁定/解锁、预览、恢复位置；战斗中不打开新设置，不执行布局变化。

## B. 变形术ID一次核验及多目标两步

本机历史未确认变形术实际成功ID，因此不猜118、12824等等级映射。界面首先显示“变形术（成功ID待核验）”，ID0只是未配置标记，不传作施法ID。

1. `/tef multi`后主动开始。手动对可变形的敌对目标成功施放一次变形术。第一次保持1/2；这是获取本会话公开成功事件证据，不算完成步骤。
2. 脱战后**不要pause/reset/reload或切换场景**，直接 `/tef confirm`。命令仅接受本运行代次、当前未核验步骤的公开player成功ID及独立安全查询的同名“变形术”。成功后保存唯一精确匹配ID、重置并暂停。
3. 如确认提示NO_VERIFIED_NAME_SUCCESS，执行 `/tef diag`并正常落盘；可能是事件参数/名称查询未知，不强行推进。也可以在菜单诊断看到公开ID后，由用户明确核对并手工编辑配置。
4. 再主动开始，重新成功变形术应从1/2到2/2，推荐5143；提前施放5143不跳过变形术。
5. 奥术飞弹成功开始引导后完成。提前取消仍可能已经完成；7268子事件和CHANNEL_STOP不重复推进。
6. 切回单体应暂停、回第一步；多目标已确认ID应独立保存。测试暂停时成功不推进、继续保持位置、重置首步、完成不重启，最后开启循环完成一轮再关闭。

## C. 旁路能力观察（可单独另测）

1. `/tef single`并开始，不要求施法。设置“场景与验证”或 `/tef sample`执行一次显式采样；不后台扫描。
2. 有/无目标、范围变化、读条/引导时分别采样。各字段应为公开正反或明确未知；ready和gcdClear始终UNKNOWN，动态结果无候选。
3. 开启原本使用的姓名板显示，用可见单位变化检查visibleEnemies。没有姓名板是0个可见单位，不意味着场上0敌人。友方、死亡、未知不可攻击状态不得混成确定敌人数。
4. 若有≥3个公开可攻击且存活的可见单位，1秒内连续两次 `/tef sample`仅产生multi建议；实际scene保持single、步骤不变化。2个保持；未知或采样超过1秒撤销连续确认。
5. target/战斗/施法事件、停止、场景切换撤回旧证据；超过1秒后刷新显示过期。本页面显示的是最近手动采样结果，非持续实时状态。

## D. TEK只读观察（可单独另测）

1. 保持TE不输出信号，TEF设置“TEK适配”点击只读信号，或 `/tef protocol`。
2. 左上出现20格TEAP v3，现有TEK用自动定位读取。应看到waiting/paused或观察帧拒绝输入；Token0，不应有真实按键发送。
3. 这一步验收屏幕定位/DPI与观察帧，不能证明自动释放。协议开启状态不持久化；UI缩放变化关闭输出，需要重新开启。
4. 再 `/tef protocol`关闭，或 `/tef hide`同时暂停并关闭。

## 停止与落盘

`/tef stop`停止练习；开启过协议时用 `/tef protocol`关闭，或直接 `/tef hide`。正常 `/reload` 或退出游戏落盘。reload后确认暂停、协议关闭、配置和HUD偏好保留。

告诉助手“已落盘”后，只读取TEF自己的 `WTF/Account/<账号>/SavedVariables/TACTIC-ECHO-FOREVER.lua`，分析TEF_DB当前会话的精确成功、偏离、确认配置及research安全摘要；不读取其他插件数据库。诊断最多128条，建议上述各段分轮实测并落盘，避免同轮过长覆盖关键记录。
