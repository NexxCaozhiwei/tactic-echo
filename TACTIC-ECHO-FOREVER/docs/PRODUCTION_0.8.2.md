# TEF 0.8.2 手动介入与进战短测

1. /reload确认0.8.2；如果版本不是0.8.2，不把测试结果当新版。/tef pause先停止，确认当前职业/精确绑定与存活目标，使用116→205→205→143，关闭循环便于检查。仅TEF一个信号源，TEK UI联动模式。
2. 选自动启停，开启意图，脱战待命。用顺序外技能手动进战（可复测5019）；该技能不能计步。其他读条/引导期间保护，实际空闲后应从当前116恢复，不再点启停。
3. 运行时插入其他技能键，再松开。TEK按住让权，松开经过原恢复门禁后继续当前推荐。不要把“键仍按住时不派发”当失败，不要求绕过手动优先。
4. 读条中移动打断，再停下；意图不关、当前步骤不推进，重新校验后尝试原步。合格瞬发技能移动时没有TEF全局移动阻断；读条技能可能游戏判定失败，不因此跳步或暂停意图。
5. 静止主动取消/中断当前技能也应保持意图、重试原步。这是用户本轮要求覆盖旧版“取消即永久停止”策略。停止自动尝试必须显式点主卡停或/tef stop。
6. 验证两次205须独立成功、后续143正常；7268与顺序外技能不计步，迟到失败/成功不消费新尝试。设置仍零Token保留意图；关闭重新校验。手动停止后按移动/其他技能或进战不能复活。
7. 测完/tef stop，再正常/reload或退出，回复“已落盘”。只读TEF_DB和TEK自身trace，区分发送与精确成功；新版恢复尚未实机验证。
