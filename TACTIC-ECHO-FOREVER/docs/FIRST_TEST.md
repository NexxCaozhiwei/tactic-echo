# 首轮短实测SOP

此文为原四步SOP。当前0.1.3临时精确ID配置请改用RANK_SEQUENCE_TEST_0.1.3.md，勿按本页期待原顺序。

只需操作TEF，不需要启动TE或TEProbe。固定使用当前已学的四个样本等级技能；面板仅提示人工顺序，不保证可用。

1. `/reload`，确认出现“TEF v0.1.1 已加载，默认暂停”和暂停1/4面板。新安装若/reload后插件未枚举，回角色选择界面在插件列表勾选TACTIC-ECHO-FOREVER再进入。不要通过修改Interface或加载过期插件掩盖错误。
2. 主动点击“开始”或 `/tef start`。手动施放寒冰箭，成功后应2/4火球术；在火球术步骤先读条后Esc取消，应仍2/4。START/STOP/中断不得推进。
3. 仍在2/4时插入寒冰箭或火焰冲击，应保持2/4；`/tef diag`应有OUT_OF_SEQUENCE。随后正常完成火球术，应到3/4；手动火焰冲击后应4/4。
4. 手动发动奥术飞弹，5143成功后应“完成”。随后7268子事件及CHANNEL_STOP不得重新开始/多次推进。可另一次从头练习，在飞弹成功开始后立即取消：本版仍可能已完成，这是明确的开始引导语义。
5. `/tef reset`应暂停1/4；开始并到2/4后暂停，期间正常火球术成功也保持2/4；继续后重新施放一次火球术，才应推进。暂停/重置前已开始的读条，恢复后才成功不应接管新代次；重新开始新的施法再验证。
6. 默认循环关闭，完整四步应停在“完成”；勾选“完成后循环”并重新开始，完整四步应回到运行1/4，每个成功事件仍只走一步。关闭循环后本轮末步正常结束。必要时拖动背景，reload后位置恢复但活动运行状态不恢复。
7. 如某步不动或出现未解析，立即 `/tef diag`。记录当前步及固定原因，不猜ID，不连续乱放技能刷满日志。IDENTITY_SECRET/UNKNOWN、NO_CURRENT_INITIATION表示标识或起始关联限制；公开的不同spellID偏离表示需要核对当前等级。以实际结果验收，不拿模拟测试替代。
8. 最后 `/tef stop`，再 `/tef diag`记录会话与淘汰数。正常 `/reload`、返回角色选择或正常退出游戏落盘；不要强制结束进程。reload后应默认暂停1/4，不延续旧事件关联。
9. 完成正常落盘后告诉我“已落盘”，可附哪些步骤符合/不符合预期。我将只查 `_cn_beta_/WTF/Account/<账户>/SavedVariables/TACTIC-ECHO-FOREVER.lua` 中的TEF_DB（必要时同名备份或角色对应同名文件），核对文件时间、版本、客户端、session/generation、事件类型、匹配/偏离/未知/暂停忽略/完成和淘汰数；绝不读取其他插件数据库代替TEF结论。超过128条导致早期数据淘汰时明确缩小结论。

建议一轮正常四步、一轮取消/偏离、一轮生命周期/循环，合计约数分钟。未发动真正成功事件的技能不要求推进；本版也不能从错误分类推断资源、目标、视线或精确冷却原因。
