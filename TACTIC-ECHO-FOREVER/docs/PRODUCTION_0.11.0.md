# TEF 0.11.0 交付与首轮APL验收

本轮只修改TEF与其文档/基线；TE 1.5.12、TEK和TEProbe源码、其他插件SavedVariables不变。默认原固定序列，APL需显式启用；原autoStart偏好仍只建立新意图。安装目录独立TACTIC-ECHO-FOREVER，Interface16001；部署前备份，只复制安装清单且逐文件SHA256核对，ZIP只有一层TACTIC-ECHO-FOREVER根目录。

## 验证

现有193项及新增52项APL专项，合计245项Lua5.1模拟，覆盖用户列出的16项及能力/天赋/等级、Secret/缺API/调用失败、公开冷却0/0、GCD未知、无专精身份、混合天赋、当前SENT锁定、成功后再求值、相邻重复、取消重试、reload和迟到身份、128条日志饱和、唯一Runtime/Packet、缓存重入失效及UI草稿。另有TOC加载、基线、Lua语法、TEK互操作及仓库回归。

均为模拟或文件验证。未在游戏中实测本版本APL、天赋rank provider、法术书实际等级、动态派发或新UI视觉。历史固定序列游戏成功不作为APL成功证据。源目录数据来源unverified且声明70170；70338节点不符必须UNKNOWN，不绕过确认。

## 短实测

1. `/tef pause`，然后`/reload`，确认加载0.11.0，再执行一次`/tef pause`（已有autoStart偏好可能创建新意图）。只启用TEF信号源。`/tefui`保持设置打开，先核对原人工/代码序列仍在、快捷键与循环配置仍在。
2. “职业APL”页选**火球术**填充；五个可选规则先全关，自动启停和autoStart按已有偏好处理。若同技能多个绑定等级有歧义，填实际已学且放在默认动作条的精确ID（例如本角色已证实143），点保存。配置修改停止意图。
3. “推荐配置”页当前单体配置选**APL**。关闭设置，选择存活敌对目标，按独立启停键主动开启（或`/tef toggle`）。自动模式需进入战斗。HUD应显示法师APL、当前rule及天赋诊断；没有现代专精选择，后续固定步骤预览关闭。
4. 看状态是否推荐火球并派发；若显示`APL等待公开条件`/阻断，同样保留记录。**GCD61304 NO_DATA或自身冷却Secret是本版预期的真实限制，不能通过等待估算GCD解除。** 连续派发是否inputSent、游戏是否成功须分别核对。请不要用“UI有推荐”当游戏施法成功。
5. 确认可派发后，再单独测试火球提前取消、移动及插入别的技能；不应确认APL当前收据，意图保持，公开条件恢复后再求值。奥术飞弹作为填充另测成功开始及7268子事件，开始成功只消费一次，提前取消引导可能已经消费。
6. `/tef pause`后脱战开设置，改填充为寒冰箭重新启动，再测偏好切换；配置修改不应自动复活旧请求。仅角色实际学习的能力可参加。若角色已有炎爆/气定/奥强，每次只开一个规则验证；缺天赋或rank未知不应推荐。实际换天赋/学技能后应自动dirty重采，无需reload；不得为测试临时改造SavedVariables天赋。
7. 多目标配置单独选APL，魔爆开关开、阈值3，使用可见敌方计数测试；可见计数不是命中数。自动场景切换仍未上线，需手动选择多目标。普通循环/目标或脱战重置不能复活旧快照；APL成功后反复求值而不是按1/1完成停机。
8. 停止后切回人工/代码，确认原序列与次数仍完整并可按旧流程练习。随后`/tef pause`，正常`/reload`或退出，确保落盘，再回复“已落盘”。届时仅读取TEF_DB的配置、诊断中apl.rules/actions/talents和成功事件，单独关联TEK自身trace；不读别的插件数据库代替结果。

设置中只显示少量相关规则结果，完整最近变化保留在有界诊断。Build显示?表示某系rank覆盖不完整，不能解释为0点。若APL不能派发，先按字段找实际UNKNOWN来源，不调整门禁掩盖问题；固定序列仍可回切使用。
