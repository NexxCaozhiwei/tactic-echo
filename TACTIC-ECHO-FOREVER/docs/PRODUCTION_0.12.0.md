# TEF 0.12.0部署与验收

根据用户五份WotLK材料重设规则，不是WotLK全能力移植。设置「职业APL」选择奥术、火焰或冰霜模板；规则列表可滚动，逐行显示原始条件、KEEP/ADAPT/DROP/BLOCKED和最近结果。未进入子列表的规则显示未评估，不伪造结果。

三个模板属于同一法师Class Pack，不需要现代专精。手选模板是策略意图，不声称已确认天赋构筑。依模板末尾填充为奥术冲击/火球术/寒冰箭；显式覆盖只影响末尾普通填充，条件飞弹不因此成为触发已确认。

奥术：奥术强化、冰冷血脉、镜像按源default顺序；AoE调用仅手动multi且公开visible count>2；气定仅在该AoE列表原位置。奥冲层数飞弹/弹幕不执行。火焰：冰冷血脉、移动且许可的火焰冲击、末尾火球按源顺序；所有条件炎爆与燃烧子列表被阻断，原AoE关闭。冰霜：镜像、冰冷血脉、奥术强化按源位置，末尾寒冰箭；proc、pet/glyph、withinN等未闭合规则不执行。

仍要求精确已学ID、公开usable/power_ok/范围、ownCD和GCD。前轮实测61304未知及自身冷却未知的问题未解决；此次重设优先级不授权未知状态派发。未知不解码、不估算、不用图标或DurationObject替代。TE与TEK代码和协议不变。

验证：253 Lua5.1模拟（193+60），TOC/版本一致，5来源SHA256与84源规则逐行核对；789回归通过、7跳过、17子测试。新版HUD/滚动UI、模板与派发未实机验证。

## 短实测

1. `/tef tekoff`、`/tef pause`，然后`/reload`确认0.12.0。
2. 在推荐配置选APL，在职业APL选火焰模板与依模板，查看滚动优先级；炎爆应显示BLOCKED，火焰AoE调用DROP。
3. 选择敌对存活目标，开启练习/许可，手动进战。若无候选，保留阻断提示，勿反复重置；GCD未知仍是有效阻断。
4. 停止派发后再切冰霜模板，核对默认末尾寒冰箭；切模板会停止并清旧请求。
5. `/tef tekoff`、`/tef pause`，正常`/reload`或退出落盘，回复已落盘。只读取TEF_DB继续分析。
