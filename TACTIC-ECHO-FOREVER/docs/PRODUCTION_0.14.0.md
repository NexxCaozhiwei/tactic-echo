# TEF 0.14.0 条件APL

本版按用户授权覆盖0.13.0的“CDM、蓝量百分比、精确距离未启用”限制，原配置与固定序列不自动改写。游戏入口`/tefui`→自定义APL，规则条件区和最近观察区分别可滚动。

## 拖入

支持拖到“拖入技能”按钮、模块空白、已有规则行，或拿着技能再左键点击按钮。显式注册拖放/左键接收并刷新控件。技能书游标取公开第四返回位精确ID；动作栏action游标只在当前GetActionInfo明确返回spell时取公开精确ID。宏、物品、未知、Secret都拒绝，显示固定原因并保留游标；添加成功才ClearCursor。模拟无法证明实际客户端拖入成功，本轮须专项验收。

## 条件

- 蓝量：UnitPower(player,0)/UnitPowerMax(player,0)×100，只在两值均官方检测为公开、max>0且current位于0～max时计算。支持<、≤、=、≠、≥、>；阈值0～100，不四舍五入。任一Secret/失败为UNKNOWN，不读取/保存Secret原值。
- 距离：UnitDistanceSquared(target)必须checkedDistance公开true且平方距离公开非负，才能sqrt取得数值；同样六种比较，阈值0～2000码。不从技能范围布尔、位置、UI标签或物品测距猜精确距离。官方定义提供签名，不保证敌对NPC当前环境可查询；checkedDistance=false/Secret/缺API均等待，不能宣称本版已实机取得敌对目标精确距离。
- CDM：选择增益活动（TrackedBuff/TrackedBar）或冷却活动（Essential/Utility），配置独立目录SpellID。仅CooldownViewerCooldownInfo.spellID精确匹配，linked/override不当身份；每类目录≤128、帧≤80，查询使用TEF自己的API/帧读数，不读其他插件数据库、不hook其他插件。frame.isActive公开false才满足“未活动”，true才满足“活动”；缺帧、映射未知、冲突、Secret、扫描失败不当false。可填116观察寒冰箭目录、133观察火球术目录，不因此授权116=205/133=143成功别名。CDM状态是活动信号，不是Aura真值；冷却未活动条件仍需自身冷却ready，不从CDM单独合成ready。
- 移动：不限/移动中/站定；可见敌人数上下限仍显式实验开启。各额外条件AND连接，不限即不要求该项。

必需条件仍包括战斗、已学、usable、资源足够、技能范围、自身冷却、真实BindingToken与原目标/施法/引导/TEK门禁。GCD条件不检测。自身CD未知依然阻断，不由新增数值或CDM解除。

增加精确5019魔杖。其技能范围仅NO_DATA时可回退已有验证当前动作槽范围，不用Secret/false回退；已经射击或状态未知不再派发开启键，成功收据不是每发弹丸计数。法师12种登记技能及5019可用，其他未登记语义仍阻断。

## 验证与实测

284 Lua5.1模拟（194原功能、60模板、18自定义、12新条件），涵盖六比较边界、Secret/零max、距离checked、CDM公开false/true、缺帧/linked/冲突/超限、四条例子、5019、数字保存、动作栏及点击/拖放、临派发前新条件变化撤销。TOC及版本/来源检查通过。模拟与部署哈希不代表实机派发或敌对精确距离可读。

1. `/tef tekoff`、`/tef pause`、`/reload`确认0.14.0。先只测拖入：技能书143拖到按钮、持有205后点击、动作栏直放2136拖到按钮；应新增精确ID且不自动派发。删除多余行，保存后reload确认持久。
2. 首个条件短测仅一条5019，蓝量<20、站定，距离/CDM不限。主动开启并进战，观察蓝量百分比或固定UNKNOWN分类；蓝量阈值两侧各约10秒核对，魔杖已活动不应反复按键关闭。若资源Secret，保留UNKNOWN日志，不猜低蓝。
3. 停止后另测一条205，CDM增益/未活动/116，距离不限；把对应条目加入Blizzard CDM展示配置，观察目录/帧公开状态，正常施放/切目标等变化各停留5秒。缺帧应明确UNKNOWN，不能当无增益。143/133单独测，避免混合解释因果。
4. 最后单独启用距离<20，在同一存活敌对目标附近/远离各10秒，观察距离与distanceReason；若DISTANCE_NOT_CHECKED或Secret，本客户端这条路径尚不具备该目标精确距离条件，保持阻断并落盘，不用范围布尔代替。
5. 单项验证后再组合四条例子，核对优先级及首次合格规则。停止后正常reload/退出，回复“已落盘”，下一轮仅读TEF_DB分析公开结果和固定原因。

API依据本机build70338的UnitDocumentation.lua、CooldownViewerDocumentation.lua；帧读取方法参考只读TEProbe/Probes/CDM.lua。S53/S54只有代表性CDM活动闭环，本版按用户要求将活动信号设为实验规则条件，没有升级为Aura或ready的事实证明。
