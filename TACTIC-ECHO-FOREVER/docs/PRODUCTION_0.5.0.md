# TEF 0.5.0 生产实测

1. `/reload`确认0.5.0，默认暂停、TEK许可关闭。只保留TEF或TE一个信号源。桌面TEK使用本次构建的UI联动，无需Python验收脚本。
2. `/tefui`打开设置中心，`/tef hud`显示新HUD，`/tef test`打开保留的旧测试面板。核对名称、进度、真实键位、CD/充能；未知CD显示?，不证明ready。设置打开时撤回请求。
3. 先选好合适目标，将精确等级技能直接放默认动作栏并绑定支持的键位。关闭设置，开启练习和许可，点HUD“派发”或请求快捷键。每步主动请求，测试116→205→205→143；相邻205需两次独立成功。失败不推进，修正条件后重请求。
4. 取消火球术不推进；插入顺序外技能不跳步。多目标118→5143测试引导成功开始即完成，7268不重复，提前取消可能已完成。检查暂停、继续、重置首步暂停、完成停止、循环回首步但不自动请求。非白名单输入仍触发手动让权；事件撤回前可能按限频重复发送。
5. `/tef tekoff`及`/tef pause`停止，必要时停止桌面TEK。正常reload/退出落盘后回复“已落盘”。仅读取TEF自身成功收据及TEK自身trace分别核对，不能以其它插件数据库替代。
