# TEF 0.7.0 交付与首轮实测

S37已有116自动请求，但点击“派发当前”撤销连续状态，116成功后没有205请求。本版单步按钮不再撤销或替换自动请求；统一运行意图和唯一业务心跳衔接后续步骤。精确SUCCEEDED确认后，实际读条/引导消失才请求下一步。当前步失败/中断停止；顺序外成功只记偏离。

高级TEAP和TEK许可默认开启，不等于输入。自动启停默认脱战待命、进战运行；手动模式可脱战运行；脱战后停止模式需要战斗内主动启用，脱战即停止，再进战不复活。手动暂停不能被进战恢复。自动启动默认开，仅首次进入世界建立新意图，不恢复旧请求/GUID/代次/步骤。切图、目标/职业配置变化、设置编辑停止旧请求，选择目标后再启用。

职业、公开专精ID（无专精API时base）、单体/多目标配置隔离。旧法师配置仅迁移MAGE:base，法师初始专精可复制练习；后续切到未配置专精显示未配置。其他职业没有预设，不猜技能。人工和代码序列独立选择，代码提供者在Recommendation.lua声明，目前只有明确法师样本；缺少代码配置不回退人工。APL及自动多目标切换仍为后续工作，旁路研究不授权输入。

固定序列是输入尝试，不保证ready。不照搬TE AutoBurst冷却/GCD准入；保留公开合法技能、真实直接默认动作条绑定、公开目标/范围/usable双布尔、静止、文本焦点、读条/引导保护。UNKNOWN不伪造可用。沿用TEAP v3及TEK前台、Hook、手动让权、新鲜度、重放、限频门禁，不新增输入通道或宏支持。等待事件时TEK可能重复发送，不能承诺单请求仅一个物理按键。

## 首轮测试

1. 游戏只保留TEF信号源，桌面TEK选择UI联动。`/reload`确认0.7.0；自动模式脱战显示待命、Token0。升级保留明确关闭偏好；若高级信号/许可曾关闭，到设置TEK适配页开启。
2. `/tefui`检查职业档案。法师单体人工配置应保留116→205→205→143，各步精确自身ID。关闭循环；必要时每行填写一个ID，保存重置暂停。将对应精确等级技能直接放在默认动作条并配置键位。
3. 关闭设置，先`/tef pause`，再`/tef manual`、`/tef reset`；选择适合的存活敌对目标，静止。只点HUD“运行”一次。不要再点单步或手动按后续技能；观察116、205、第二次205、143与完成。失败保留现场诊断，用`/tef diag`查看固定原因。
4. 重置运行；当前205取消时不得计步，自动运行应停止；主动运行继续当前步。插入顺序外技能只能记偏离，不能跳步。
5. 多目标人工配置118变形术→5143奥术飞弹。切场景重置暂停，选择适合目标后运行；5143成功开始引导完成步骤，7268子事件不得再推进。提前取消引导可能已完成，CHANNEL_STOP不能确认完整引导成功。
6. 检查暂停保持步骤、继续、重置首步暂停、完成不重启；再开启循环，末步回首步且一次事件只推进一格。
7. `/tef auto`并启用，主动开战后运行，脱战待命；主动暂停后进战不能复活。`/tef combatstop`在战斗中主动运行，脱战停止，再进战仍须主动运行。自动模式不会自动拉怪。
8. 设置总览“录入”组合键后“应用”，已有动作绑定会拒绝。关闭设置用该键启停。战斗内修改延迟脱战应用。游戏原生按键设置也有TEF派发启停。仅临时override TEF动作，不修改动作条技能绑定或调用SaveBindings。
9. 非法师角色应显示自身档案、未配置，不借法师推荐。人工填入该职业确认过的精确技能再测。

停止用HUD暂停或`/tef pause`，必要时`/tef tekoff`关闭高级许可；Token应归零。正常`/reload`或退出落盘，回复“已落盘”后只分析TEF自身SavedVariables，可结合TEK自身trace区分请求、Windows发送、游戏成功。不能读取其他插件数据库代替。自动启动开启时reload后新自动模式脱战待命；希望保持关闭请先关闭自动启动。

## 证据范围

本版控制器、三模式、职业配置、快捷键与连续链仅模拟验证，尚未游戏实测。旧版成功与真实输入不能证明本版连续派发成功，哈希只证明安装一致。
