## 使用

`/tefui` → 派发总览：如F5被占用，先开启“临时覆盖已有绑定”，再录入F5。该键临时作为TEF启停，不再执行其原功能；清除快捷键/关闭覆盖会恢复原生绑定。不会写SetBinding/SaveBindings，不改其他插件。无法检测已有绑定、Secret、调用失败仍拒绝。战斗中保存后等待脱战应用。原已保存F6保留，未经录入不自动改为F5。

“循环/重置”：不循环完成后停止；普通循环无限按序；切目标模式在目标变化（含清空）回首步；脱战模式在PLAYER_REGEN_ENABLED回首步。后三者末步均回首步。重置清次数、旧关联/请求，保留意图；自动模式脱战待命，stop模式脱战停止，手动模式仍按其既有规则。循环模式变更重置并停止，需主动启用；暂停不被切目标或脱战复活。普通循环在目标变化或脱战时保持游标但仍撤销旧请求。旧loop=true迁移normal，false迁移none。

“标签样式”：主卡与预览卡分别设置键位、充能、冷却、状态、卡片标题；整体文字设置技能名称和状态/步骤进度。字号8–30、缩放0.6–2、五种锚点、X±100/Y±150、六种颜色、描边预设和显示开关，当前标签可恢复默认。整体文字锚点相对HUD，卡片标签相对卡片。无新轮询、不保存DurationObject、不改变CD/GCD/派发输入。实际阅读参考addon/!TacticEcho/UI/ControlPanel.lua的ensureTextStyle/buildTextStyleSection/buildHudLabelStyles、ApplyToggleHotkey，以及UI/TacticalIconButton.lua的textStyle/applyFontStyle；不依赖TE内部函数或数据库。
