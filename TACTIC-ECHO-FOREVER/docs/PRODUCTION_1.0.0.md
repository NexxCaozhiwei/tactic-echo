# TEF 1.0.0 首个基线发布

1.0.0将0.14.3的当前功能作为正式开发基线冻结，不表示所有职业/所有条件均已验收。适用无限服1.60.1/build70338/Interface16001/zhCN；TE插件保持1.5.12，与TEF只能启用一个TEAP信号源。

## 安装与使用

单独插件包解压后将TACTIC-ECHO-FOREVER文件夹放入Interface/AddOns，目录内直接包含同名TOC及Bindings.xml。Windows组合包中的TACTIC-ECHO-FOREVER是相同运行文件；TEK.exe放到独立工具目录运行，不放入AddOns或WTF。TEK配置仍由客户端在自身用户目录创建，不随发行包携带本机配置。

登录或reload不恢复旧请求/成功关联；当前默认自动启动偏好可能创建新运行意图，自动模式脱战待命、进战重核后运行。初次安装先在/tefui检查自动启动、派发许可、三种运行模式与快捷键，配置好技能和真实默认动作槽绑定，再主动测试。TEF与TE不要同时输出信号。

人工序列每场景最多16步、每步1～99次，按精确成功事件计数，支持普通循环、切目标重置和脱战重置。自定义APL当前首包法师，手工排序选择第一条条件满足的技能；移动、CDM活动、公开蓝量、精确距离和实验可见敌人数条件均独立配置。冷却数值检查默认关闭，不声称推荐一定立即可放；显式启用或其他已选条件UNKNOWN则跳过该规则。旧WotLK模板只有已适配公开条件可执行，BLOCKED/DROP均可见。

## 实测边界

S76/0.14.3保留战斗内116/143/5019候选和请求、4条匹配成功收据，CDM公开状态、冷却未查询及最新Bindings警告消失。版本号冻结不新增实机证据；没有以构建成功或进程存活证明Hook/真实输入成功。

仍受限：蓝量Secret不比较，UnitDistanceSquared未检查有效时不估算码数，CDM缺帧/Secret/冲突不当不活动，也不当Aura真值；其他职业没有提供通用最优APL。自动敌人数切换仍旁路。5019固定N次成功到下一技能的公开5019读条交接已模拟验证，但S76运行的是APL，未完成该固定序列验收。先成功而后读条消失的语义保持，不强写castPresent=false。
