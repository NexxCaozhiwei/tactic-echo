# TEF 0.8.0 短测

本轮只修改源码并打包，客户端仍保持此前安装。安装时将 ZIP 的唯一 TACTIC-ECHO-FOREVER 目录复制到 AddOns 同名目录，先备份旧 TEF，不改其他插件或 WTF。仅一个 TE/TEF 信号源，桌面 TEK 保持 UI 联动模式。

1. /reload 后确认 TEF 0.8.0，先 /tef pause。自动启动创建新意图，不恢复旧身份；默认自动启停脱战为待命。若希望每次登录关闭，请关闭自动启动偏好。
2. 右键主卡打开设置，确认模式、热键、当前职业/专精/场景配置及两个高级开关。主卡左键与正式绑定、自定义热键都只切换同一个派发意图。
3. 用已确认的 116→205→205→143 配置测两次独立 205。手动模式允许脱战练习；自动启停进战才运行；脱战后停止模式脱战清意图。选择有效目标并确保精确技能存在真实默认动作条键位。
4. 运行时开设置：意图仍开启、状态待命、Token0、旧请求撤销。关闭后重新校验并恢复。切换目标、短暂文本焦点或移动：阻断但保留意图；条件恢复后重新协调，不消费旧目标任务。
5. 火球取消/失败不计步，当前步失败会停机；顺序外技能不跳步。5143 成功开始引导可计步，7268 不重复；取消引导可能已完成，CHANNEL_STOP 不确认完整引导。
6. 检查六种主卡状态、Hover/Pressed/Tooltip、右键设置、锁定/拖动、缩放；按键/主卡/设置开关显示一致。高级许可或协议关闭立即清意图，重新打开不会自动复活。
7. 关闭循环完成后应显示完成；主动开启循环后末步回首步，一事件只走一步。/tef hide 仅隐藏，不停派发；停止必须 /tef pause 或 /tef stop。诊断单步在设置打开时拒绝，关闭后 /tef dispatch。
8. 测完 /tef stop，再正常 /reload 或退出落盘。回复“已落盘”后只分析 TEF_DB 和 TEK 自身 trace，不以其他插件数据库代替，也不以 inputSent 单独证明游戏施法成功。
