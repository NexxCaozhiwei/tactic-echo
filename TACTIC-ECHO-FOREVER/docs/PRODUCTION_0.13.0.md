# TEF 0.13.0 自定义APL

## 编辑与运行

设置中心新增“自定义APL”。单体、多目标分别编辑，每套最多16条。手输精确SpellID或从技能书拖到“拖入技能”，使用上下按钮排序、编辑按钮选择条件、删除按钮移除。修改先保留为草稿，点击“保存并选APL”才保存并选择对应场景APL来源，同时停止旧运行；关闭设置后主动开启。切换编辑场景会放弃未保存草稿，请先保存。空列表不产生推荐。

首版仍采用MAGE_FOREVER_60，仅接受当前官方技能信息可解析为以下已登记技能的精确ID：火球术、寒冰箭、灼烧、奥术飞弹、火焰冲击、炎爆术、奥术强化、气定神闲、魔爆术、奥术冲击、冰冷血脉、镜像。未学、不支持或未解析的技能明确阻断；不把116/205或133/143自动合并。成功事件仍匹配当前精确ID，7268子事件不确认5143。没有新增其他职业技能推测。

每次从上往下选择第一条满足公开条件的规则；成功后重新评估优先级，不按固定序列轮换。首条持续满足时可持续选择首条。所有规则都显示结果，后续满足但未选中表示前面已有合格规则。

## 条件与证据边界

必需条件：战斗内、精确技能已学、usable=true、资源不足=false、技能在范围内、自身冷却明确可用，以及原有真实绑定、目标、施法/引导和TEK门禁。GCD不检查，不能把这个例外用于伪造自身冷却ready；如果自身冷却UNKNOWN，仍等待。

可编辑额外条件均以AND连接：移动不限/移动中/站定；冷却活动不限/活动/非活动；可见敌人数上下限（空白不限）。范围是该技能对当前目标的公开布尔，不是精确码数；资源是公开不足布尔，不是蓝量百分比。冷却活动是独立公开isActive，不能替代ready，与自身冷却可用要求冲突时没有候选，不自动放宽。

敌人数必须显式打开实验选项，最多扫描40个当前可见姓名板并核对公开单位存在、敌对、存活；这是可见观察数，不是战斗总人数、附近半径或AoE实际命中数。任何计数依赖未知、超限或身份重复均不能通过条件。该路径尚未在本版本无限服实机验证。

依据TEProbe KNOWN_CAPABILITIES及TEF_STATE_INTERFACE_70338（更新至S61）：S43有范围和资源不足正反样本，S47说明范围nil不能推断目标不存在；S53/S54仅取得代表性CDM活动闭环，不证明Aura或ready。当前不启用CDM条件、蓝量百分比、精确距离、Aura、表达式或猜测天赋。未知配置字段明确阻断并拒绝保存，不悄悄忽略。未读取TEProbe或其他插件SavedVariables。

## 诊断与生命周期

每条规则展示TRUE/FALSE/UNKNOWN/BLOCKED/DISABLED、固定原因及最近公开条件值，旧代次显示过期；即时派发前重新读取当前规则全部条件，再验证generation、receiptSerial和revision。保存、切换来源、重置及reload失效旧任务；最近128条诊断仍有界，记录公开移动、计数和每条条件布尔，Secret原值、API对象、目标身份不保存。自定义模式不依赖天赋诊断，因此HUD不显示误导的?/0/?构筑信息。

## 首轮实测

1. `/tef tekoff`、`/tef pause`，`/reload`，确认0.13.0加载。打开自定义APL单体页。
2. 添加2136（火焰冲击）为第一条，移动条件“移动中”；添加143（已学火球术）为第二条，移动条件“站定”。默认不启用敌人数实验，冷却活动“不限”。必须用角色实际已学ID，可用拖入识别。
3. 点击“保存并选APL”，确认停止；关闭设置，主动开启练习/派发，手动攻击合适存活敌对目标进入战斗。
4. 站定约10秒观察第二条；移动约5秒观察第一条或明确自身CD/资源/范围阻断原因。取消火球术不算成功，不应永久清意图。停止移动后重新核对。不能以模拟或插件请求判断SendInput实机成功。
5. 停止后上下交换规则、删除再加一条，保存、reload，确认顺序/条件恢复且没有复活旧事件。另编辑多目标规则，确认单体配置独立。
6. 第二个短测才显式启用敌人数实验，设置下限2；分别让一个/两个敌对姓名板可见，核对计数与UNKNOWN，不能推断实际AoE命中。不要同时混测CDM或蓝量百分比。
7. `/tef tekoff`、`/tef pause`，正常reload或退出落盘，回复“已落盘”；下一轮只读取TEF_DB分析。

模拟覆盖272例（194原功能、60模板APL、18自定义APL），包含排序、UNKNOWN、强制门槛、实验敌数、活动不等于ready、非法/Secret配置、16条上限、跨场景reload、成功重评、即时撤销、API重入、诊断清洗及编辑草稿。真实布局、拖入、范围/CD/资源及TEK实机派发仍待验收。
