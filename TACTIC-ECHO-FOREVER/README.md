# TACTIC-ECHO-FOREVER（TEF）0.5.1

独立WoW插件，默认暂停且TEK请求许可关闭。新增设置/HUD练习启停、TEK请求许可启停；游戏原生按键设置中的TACTIC-ECHO-FOREVER分类提供四个可绑定动作，不自动修改已有绑定。交付HUD采用TE原生动作条卡片视觉：当前技能、两步预览、名称/进度与运行状态，Atlas缺失安全回退；增加真实直接动作条键位、CD秒数、充能数量及单一客户端DurationObject转盘。isOnGCD仅在SPELL_UPDATE_COOLDOWN回调可信；受限或缺API显示未知，纯GCD不画自身转盘。显示ticker只刷新视觉，不用于计步或输入，不伪造ready。原测试面板保留，通过 `/tef test` 打开，`/tef hud` 显示交付HUD。HUD可脱战拖动保存位置；设置控制缩放、锁定、预览及独立场景配置。

单体116→205→205→143；多目标118变形术→5143奥术飞弹，仅是人工练习。118依据2026-10-11 TEF自身S16/S17公开成功事件，不代表全部等级；仅迁移原两步待核验占位，自定义配置保留。各步精确匹配自身ID，116/205不自动等价，7268子事件不匹配。设置支持每行 `主ID:匹配ID/匹配ID`，最多32步、每步16ID，未知步骤用 `?名称`，不猜测或跳过。

只消费官方检测为公开player、合法ID、公开castGUID的UNIT_SPELLCAST_SUCCEEDED，并要求本代次SENT/START关联与当前步一致。START、STOP、取消、失败、读条消失、CDM和计时不推进；重复身份最多消费一次。暂停不消费，继续保持当前步，重置首步暂停，默认完成不重启，循环一次事件只进一格。5143成功开始引导即完成，提前取消可能已完成；CHANNEL_STOP不是完整成功。推进不强制读条消失。

协议条默认显示零Token观察帧。先开启练习与TEK许可，使用HUD“派发当前”、原生TEF请求快捷键或 `/tef dispatch`，提交当前精确默认动作条直接技能绑定。桌面TEK选择“UI联动”，不需要Python验收脚本。每次心跳和动作栏/绑定更新复核原锁定按钮、槽位、技能及键位；无关槽位更新不再撤回，失配或UNKNOWN立即撤回，不自动改用其它来源。暂停/重置/设置/目标或进战变化、对应施法事件及读条查询未知均撤回。`/tef tekstop`撤回请求，`/tef tekoff`关闭许可。

TEK共享颜色传输层已兼容标准与实测1.2伽马，沿用TEAP v3、真实BindingToken、前台、Hook、手动让权、新鲜度、重放及限频门禁。生产UI联动没有预算1限制，在游戏事件撤回前可能重复发送；不保证一次请求仅一个物理按键。没有自动ready，也不自动请求下一步；每步由用户确认施放条件并主动请求，失败不计步且需重新请求。输入收据不代替游戏SUCCEEDED。实验验收脚本仍可选用，旧验收文档的预算1要求仅适用于脚本模式。

`/tef start/pause/resume/reset/loop` 控制练习；`single/multi`切场景并暂停；`settings`设置；`sample`旁路采样；`protocol`显示/关闭信号；`diag`最近诊断；`hide`暂停并隐藏。登录/reload不恢复活动、关联、TEK请求许可或派发请求。唯一数据库TEF_DB，只保存必要配置与128条净化诊断，不保存Secret、GUID、目标身份、异常全文或其它插件数据。内存关联256、墓碑4096满安全暂停，reload清理。

自动场景/动态优先级仍为显式旁路研究，ready与gcdClear未知时不授权自动输入。Lua5.1游戏运行不依赖开发工具。0.5.0新HUD/设置已现场观察；S29实机确认四步成功及循环，TEK另有真实输入证据。0.5.1请求入口门控仅模拟验证。详见docs/FIELD_REPORT_2026-10-11_TEF_050_S29.md；下一阶段见docs/CONTINUOUS_DISPATCH_PLAN.md。模拟不是实机结论。
