# TACTIC-ECHO-FOREVER 0.9.1

独立无限服插件，Interface16001 / 1.60.1.70338。人工或明确代码配置推荐，固定顺序输入尝试，不依赖TE官方推荐或内部函数。唯一TEF_DB，不读取其他插件数据。

TEAP与TEK许可默认开启，Runtime统一管理派发意图。默认自动启停：脱战待命、进战运行；另有手动启停、脱战后停止。自动启动默认开启，在登录/reload创建全新意图，不恢复旧任务或步骤。设置、目标、焦点、施法或UNKNOWN临时阻断保留意图并撤销旧请求，条件恢复后重新核对。手动停止、配置修改、切图、关闭高级门禁和异常清除意图。希望登录持续关闭请关闭自动启动。

职业、专精、单体/多目标配置隔离。法师人工配置保留116→205→205→143、118→5143，各步精确自身ID。116/205不自动等价，7268子事件禁止计步。其他职业没有猜测预设，明确显示未配置，设置可填写已确认ID。代码序列目前只有明确法师样本，缺失不回退人工；APL与自动场景切换仍待后续。

仅官方检测后的公开player、合法ID、公开castGUID且本代次SENT/START关联一致的UNIT_SPELLCAST_SUCCEEDED计步。START、STOP、取消、失败不推进，同一身份最多一次；相邻相同技能须两次独立成功。顺序外技能记偏离。5143成功开始引导即完成，提前取消也可能已完成；CHANNEL_STOP不确认完整成功，推进不强制清除读条显示。默认完成不重启，可主动循环。

固定尝试不保证ready，不把未知CD/GCD当可用。派发保留真实直接默认动作条绑定、公开目标/范围/usable、文本焦点、读条/引导保护；普通失败/中断不计步，临时撤回并重新校验后重试同一步，无计时推进。移动不作全局门禁。单步按钮不撤销自动请求。TEK保留前台、Hook、手动让权、新鲜度、重放、限频；等待游戏事件可能重复物理发送，输入收据不代替游戏成功。

HUD沿用TE原生卡片方法，显示名称、进度、真实键位、CD、充能与单一客户端转盘；显示不授权输入。原测试面板`/tef test`保留，交付HUD`/tef hud`，设置`/tefui`。总览可选择模式、自动启动、自定义启停键，拒绝绑定冲突，战斗延迟应用，不改动作条技能绑定/宏/CVar。

`/tef auto/manual/combatstop`选择模式；`toggle`启停，`pause`停止，`reset`首步暂停，`resume`继续，`loop`循环，`single/multi`切场景，`tekon/tekoff`高级许可，`protocol`高级输出，`dispatch`单步，`diag`诊断。最多128条净化记录，会话/代次/业务轮/请求号与固定原因，不保存Secret/GUID/目标身份/异常全文。

HUD主卡左键只启停、右键设置；六状态反映Runtime，重置/单步移入诊断测试。正式启停键唯一，旧键在兼容/开发组保留。`/tef hide`仅视觉隐藏，停止使用`/tef stop`或`/tef pause`。0.25秒HUD刷新只更新已确认数字，不扫绑定或技能API。

单层`TACTIC-ECHO-FOREVER/TACTIC-ECHO-FOREVER.toc`安装到AddOns，游戏不依赖Python。只保留TEF一个信号源，桌面TEK选择UI联动。[实测与停止落盘SOP](docs/PRODUCTION_0.8.2.md)、[审计落实说明](docs/UI_RUNTIME_UNIFICATION_0.8.0.md)。0.8.2部署后仍需验证移动与手动技能恢复；0.8.0/S45历史记录不能代替新版实机结论。

0.8.2移除全局移动门禁：移动本身不清意图或阻止合格瞬发候选；真实读条/引导仍保护。顺序外技能不计步；撤回尚未发起的候选会释放等待，已有当前SENT/START则保留成功关联。按键手动让权及松开恢复仍由原TEK处理。普通失败不再永久暂停；只有显式停止、硬生命周期或异常关闭意图。

0.9.0推荐配置页支持技能拖入、手输精确ID、上/下排序、删除、每步1–99次；每套最多16技能步骤。高级文本如205:205*3，保存才生效且暂停重置。原17–32步配置保留，须缩减才能运行；清空可保存为未配置。每次独立成功计一次，暂停保留，reset/reload清零；默认一次。人工和代码来源独立，编辑人工不会自动切换来源。
