# TACTIC-ECHO-FOREVER 1.0.0

TEF独立插件的首个发布基线，适用无限服1.60.1/build70338/Interface16001/zhCN。人工序列、单体/多目标配置、自定义APL、HUD和TEAP v3/TEK共享传输链独立于TE官方推荐，不读取其他插件数据库。

安装时将同名文件夹直接放入Interface/AddOns；组合包TEK.exe放独立工具目录运行。TE与TEF只启用一个信号源。登录默认自动启动偏好可建立新意图，自动模式脱战待命、进战重核；请先在/tefui检查自动启动、许可、快捷键和技能实际绑定。

人工每套最多16步、每步1～99次，精确成功才计数。自定义APL首包法师，手动优先级，冷却检查默认关闭，已选未知条件不授权；不承诺技能立即可施放。CDM活动不等于Aura真值/自身ready。蓝量Secret、精确距离未确认和5019固定次数交接的实测限制明确保留。

使用、限制和短实测见[1.0.0说明](docs/PRODUCTION_1.0.0.md)，发行资产见[Release说明](docs/RELEASE_1.0.0.md)，历史实测见[S76报告](docs/FIELD_REPORT_2026-10-11_TEF_0143_S76.md)。首版APL技术架构见[APL架构](docs/APL_ARCHITECTURE_V0.md)。版本推进不增加运行能力或实机证据。
