# TEF 0.10.1 基线

## TEF 0.10.1 界面修复 — 2026-10-11

- 统一按钮选中样式：鼠标移入/移出及刷新后保持选中底色、边框和文字标记，循环页常驻显示当前模式与循环开关。
- HUD去除设置按钮与整块半透明底纹，保留主卡右键设置和/tefui。
- 设置页分区改用页面BACKGROUND/BORDER纹理，标题和正文在同一页面OVERLAY层，消除高层底框遮字；压缩HUD外观页说明避免与缩放分区相交。

# TEF 0.10.1 界面修复与验收

选项高亮丢失的原因是OnLeave通用样式覆盖了刷新时绘制的选中边框。统一SetControlEnabled根据持久selected状态绘制，增加选中底色、边框及文字标记，循环页显示当前模式与循环开启/关闭。更改循环模式仍重置并停止，需主动开启派发；这是既有行为。

TEFUI分区原先用高一层子Frame的Backdrop盖住父页面FontString。改为父页面BACKGROUND/BORDER纹理，标题和正文用同页OVERLAY层；HUD外观说明减少为三行，与缩放分区分离。HUD移除独立“设置”按钮和根容器底纹，保留图标框、主卡右键设置、拖动及/tefui。未修改用户SavedVariables或TE/TEK运行链。

193项Lua5.1模拟、18TOC入口与互操作检查通过，新增鼠标移开/再次选择/切页选中保持、底层纹理布局关系、无HUD根底纹及右键设置可用。离线布局断言不是实机视觉验收。

实测：/reload确认0.10.1；/tefui打开循环/重置，轮流点普通/切目标/脱战/关闭，将鼠标移开或切页返回，选中标记及当前模式应一致。检查派发总览/HUD外观/高级TEK正文不再被底框遮住。关闭设置，HUD无设置按钮和整块底纹；右键主卡仍能打开设置。测试后/tef pause，正常reload/退出落盘。若发现遮字，说明页面及具体文字位置即可。
