# TEF 0.13.0

继承0.12.1。用户授权实现手动排列自定义APL，首版MAGE、每场景16条精确ID规则。固定序列仍默认，旧WotLK模板继续可选。规则配置只保存白名单标量，职业/单体/多目标隔离；保存停止旧派发，reload不恢复活动关联。

每条规则必须通过公开战斗、已学、usable、资源足够、技能范围及自身冷却。允许额外移动、冷却活动和显式实验可见姓名板计数阈值，UNKNOWN不通过；GCD不检查。CDM、蓝量百分比、精确距离未启用，不静默忽略未知配置。即时复核及旧代次保护沿用唯一Runtime/Dispatch/TEAP/TEK。

所有规则提供结果和原因，诊断仅保存公开布尔/合法ID/有界计数。TE与TEK源码不变。新增页与派发仅模拟验证，实机待用户验收。
