# TEF 0.3.0

独立交付HUD与保留测试面板；原生动作条背景、边框、圆角遮罩有安全回退，三卡片、状态与控制入口。HUD只展示，不改变步骤或派发权限；脱战应用缩放，独立保存位置。

多目标默认118→5143，118来自2026-10-11 TEF自身S16/S17公开成功事件；只迁移原两步未核验变形术占位，用户其他配置保留。不推测其他等级。

TEAP默认显示暂停/零Token观察帧。显式 `/tef tektest` 提交当前步骤人工绑定验收请求，复核当前默认动作条直接技能槽及公开真实键位，不支持猜测宏/变体/等级等价。TEAP v3使用现有目录封套2/25732、ActionCode0；收到对应player施法事件、暂停、重置、设置、目标/绑定改变或存在性未知即撤回。没有自动ready、动态优先级或自动循环派发。

TEK保持源码不变。验收强制按SOP使用验收脚本固定预算1并初始化现有Hook（旧CLI缺少Hook）；插件无法验证外部预算，无预算运行不能保证单次输入。成功推进仍只由原精确SUCCEEDED及本代次起始关联确认，输入回执不等于游戏施法成功。

Lua5.1模拟、协议与TEK dry-run为离线证据，HUD外观、客户端绑定API和真实Hook/SendInput待实机验收。部署限独立TEF目录，保留未知文件与WTF。
