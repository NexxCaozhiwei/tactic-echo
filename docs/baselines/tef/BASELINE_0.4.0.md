# TEF 0.4.0

继承0.3.0精确顺序、公开成功确认、去重/代次、独立数据库与输入边界。

增加练习启停与独立TEK请求许可（默认关闭、reload不恢复），设置/HUD/原生Bindings.xml四个快捷键共用同一函数。用户在游戏原生按键设置自行绑定，不自动写绑定，不启动外部进程或增加输入通道。关闭许可即时撤回；开启许可不自动请求，不意味着TEK已连接。阻塞分别记录许可关闭、设置打开、练习暂停、完成、未解析；上下文撤回记录具体固定事件分类。

交付HUD增加真实直接动作条键位、CD秒数和充能标量、客户端DurationObject转盘。单卡只附着最终一个对象；ignoreGCD=true查询技能自身转盘；充能公开并正在恢复时选择充能对象。所有字段经过官方检测、API/渲染各自pcall，Secret/缺API/失败不猜测。isOnGCD仅SPELL_UPDATE_COOLDOWN回调用于数值展示分类；未获自身CD证据显示未知，不估算GCD。视觉缓存只存公开标量，不保存对象或落盘，不参与Engine/Dispatch/Research。HUD一个5Hz显示ticker，协议仍唯一20Hzheartbeat，无计步/输入来自显示ticker。

验收脚本改用TEK现有AutoLocateFrameSource：初始化不即时截取全桌面定位，等待WoW前台、客户端内信号、现有定位验证与退避恢复；写trace并输出门禁状态。单次预算、真实输入明确参数、Hook/前台/手动让权/限频保留，TEK源码不修改。Ctrl+C需实际同时按键。

部署仅TEF目录、源包单层、备份与逐文件SHA256。新外观/API公开性/实际快捷键/输入待实机，离线测试不代替。
