# TEF 0.4.1 生产主动派发基线

用户明确授权TEK生产派发，覆盖0.4.0仅预算1脚本验收的交付限制。独立TEF，不修改TE运行逻辑、TEK源码或其它插件数据库。

默认暂停、许可关闭、零Token。用户主动开启练习及许可，再请求当前一步。生产入口为HUD“派发当前”、原生请求快捷键、/tef dispatch（tektest兼容）。使用桌面TEK现有UI联动，不要求开发脚本，不恢复reload前请求。

请求锁定按钮对象/名称、动作槽位、精确技能ID及BindingToken。心跳与ACTIONBAR_SLOT_CHANGED/UPDATE_BINDINGS复核同一来源；无关变化保留，失配/未知撤回，绝不重新找一个来源接管。对应施法事件立即撤回Token，只有公开且符合关联契约的SUCCEEDED计步。失败/取消不推进，不自动重试或请求下一步。

保留TEAP v3、Hook、前台、手动让权、新鲜度、重放、限频。生产UI联动无单次预算保证，游戏事件撤回前可重复发送。HUD冷却/充能只用于显示，不证明ready或授权下一步。宏与等级别名仍不猜测。

Lua5.1模拟与TOC检查、现有TEK互操作测试及仓库必需回归必须通过。部署备份并逐文件SHA256核对；真实SendInput与游戏效果由新版本实机日志分别证明。
