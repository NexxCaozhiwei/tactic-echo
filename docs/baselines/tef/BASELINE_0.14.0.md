# TEF 0.14.0

继承0.13.0。用户明确授权启用蓝量百分比、精确目标距离、CDM比较条件。仅公开UnitPower/UnitPowerMax计算比例；UnitDistanceSquared必须checkedDistance公开true；不估算受限值。CDM独立目录SpellID精确映射至公开frame.isActive，目录最多每类128项、帧每类80个，帧缺失、冲突、隐藏、Secret/检测失败不能当作未活动。CDM活动不当Aura真值，也不替代自身冷却ready。

每条配置支持<、≤、=、≠、≥、>数字比较、CDM增益/冷却活动存在与不存在、移动条件；全部AND连接，旧生命周期/即时复核/公开成功确认/唯一TEAP路径保持。5019魔杖增加到自定义推荐，保留原验证动作槽范围回退与已活动/未知拒绝重复开启门禁。

拖入通过OnReceiveDrag、左键接收及持有技能点击，公开动作栏直放技能可解析；不解析宏/物品游标为技能。配置仍草稿保存、单体/多目标隔离、每套16条，Secret原值/API对象不保存。TE与TEK源码不变；所有新条件实机公开性及实际布局待验收。
