# TEF 0.14.1

继承0.14.0。用户授权待命时根据目标与自身状态显示APL推荐；去掉自定义与旧模板推荐评估的强制combat条件，仍须通过实际配置的全部公开条件。战斗记录仍真实采样，不伪造true，不跳过范围/自身ready/资源/CDM/距离等UNKNOWN。

推荐与派发分开：唯一Runtime自动脱战待命，APL Allowed与最终Packet要求公开战斗true；预览不创建请求、关联、成功计数或派发资格。未知战斗可有只读候选，仍零Token；手动APL模式也不能借预览脱战派发。目标和条件变化由既有周期及事件重评，不新增轮询；进战必须重采核对，旧预览不得直接变成授权。

等待文案区分待命无合格规则与普通无合格规则。TE/TEK不改，固定序列模式不受此APL变更影响，新版实机待验收。
