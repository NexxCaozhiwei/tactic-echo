# TEF 0.14.2

继承0.14.1待命推荐与独立派发门禁。参考TEProbe只读CDM探测方法，身份未知的单帧继续扫描，不推测其关联，也不抹除其他精确目录SpellID帧的公开isActive结果。未匹配技能保持UNKNOWN；精确关联的Secret、冲突、枚举失败及容量超限仍保守阻断。

CDM扫描仍每Viewer最多80帧、目录最多128条；每类两个Viewer最多160个跳过帧。固定扫描原因及计数写入白名单诊断，规则页可见，不保存原值或API对象。没有添加hook、计时器、轮询或输入通道；采样和派发前即时复核使用同一逻辑。

蓝量Secret、距离检查失败、技能未登记和战斗自身ready未知不在本补丁中放宽。TE、TEK、WTF与用户APL规则不改，新版实机待验。
