# Tactic Echo 1.4.2 基线：窗口 SpellID 输入与四步设置流程

## 基线结论

`1.4.2` 修复自动注入页周期刷新覆盖窗口输入的问题，并把当前组配置整理为明确的四步流程。

## 冻结行为

- 第一步“设置窗口技能（必填）”必须说明窗口栏填写数字 SpellID，而不是技能名称或按键；只有官方推荐精确命中该技能才启动本组。
- 窗口 SpellID 支持按 Enter 或点击“保存窗口技能”提交。
- 第二步添加最多六个注入技能；第三步调整窗口、注入和饰品 13/14 的九步顺序；第四步在配置完整后启用当前组。
- 当前自动注入页仍可按 0.25 秒更新状态和只读控件，但名称、窗口及其他文本输入不得被同组周期刷新覆盖；只有切换技能组时才装载该组已保存值。
- 新组保持关闭且可完整编辑。本组窗口/注入互斥、跨启用组窗口唯一与禁止自动级联规则保持不变。
- 三组继续共享唯一 Coordinator、AutoBurst OrderedPlan、capture 和候选；活动计划期间其他组窗口只记录并忽略。

## 协议与验证

- TEAP v3 20 字节、Burst flags `0x20`、BindingToken 与 TEK 门禁均未修改。
- 必须运行基线契约、完整 pytest、两套 unittest、compileall 和全部 AddOn Lua 语法检查。
- 实机需验证输入框持续输入、Enter/按钮保存、切组装载、四步布局以及普通技能窗口实际触发。
