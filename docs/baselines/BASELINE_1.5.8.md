# Tactic Echo 1.5.8 基线

继承 1.5.7，增加用户手动切换的特殊模式。

- 设置中心新增“特殊模式”：独立切换快捷键、总开关，每专精三个独立启停的替换组，填写原技能与替换技能数字 SpellID。默认模式与组均关闭，重复启用原技能、同技能替换和无效 ID 拒绝保存。
- 仅在官方派发分支对原始官方 SpellID 做一次精确匹配，不递归替换，不修改官方推荐。自动注入候选、hold、计划及优先级保持原样；此模式不是全局禁止 AOE。
- 替换技能复用当前动作条解析、共享宏身份规则、真实 BindingToken、TEAP v3 与 TEK 全部门禁。复用 RuntimeSnapshot 精确自身冷却/充能及 GCDGate，替换技能无绑定、自身冷却未知或不可用时输出零 Token，不回退原技能。
- 手动点击、输入焦点、施法/引导/蓄力和暂停优先，不新增轮询、事件、输入通道或协议位。模式开启时 HUD 状态行显示“特殊”。
- 快捷键复用 TE 自身临时覆盖绑定方式，不改游戏动作条绑定；三个 TE 开关快捷键互相排斥，战斗内编辑延迟到脱战应用。
- 文本输入只在专精/配置容器变化时重新加载，不被周期刷新覆盖；完整规则按专精保存，随配置文件保存和恢复。

使用：`/teui special` → 设置快捷键 → 填写两栏 SpellID 并保存 → 勾选对应组 → 用快捷键切换模式。替换目标需放在有绑定的默认动作条；宏仍执行其原有正文，不自动改造成单体宏。

离线验证不等于客户端快捷键、Windows Hook 或真实 SendInput 验收。

验证：新增特殊模式行为测试 19 项通过；全量 pytest 778 passed、7 skipped、17 subtests passed；TEK unittest 227 项、AddOn unittest 243 项通过。53 个 Lua 文件语法、compileall、基线契约通过。首轮并行 TEK unittest 的 50 ms 等待出现一次时序失败，独立复跑通过；未修改 TEK 生产代码。
