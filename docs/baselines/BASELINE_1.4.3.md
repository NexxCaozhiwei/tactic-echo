# Tactic Echo 1.4.3 基线：多组 HUD 投影与紧凑设置页

## 基线结论

`1.4.3` 将自动注入 HUD 从“单一活动/匹配/选中组投影”改为“全部已启用组的有序只读投影”，并收紧设置页的操作位置与滚动高度。

## 冻结行为

- HUD 按 `autoInjectionGroups.order` 展示全部已启用组；关闭组不进入 HUD。
- 每组内部严格按自身 `sequence.entries` 顺序显示已启用步骤，每组最多九张，最多三组、总计 27 张。
- 横向爆发增长方向把不同组分行，纵向增长方向把不同组分列；卡片继续携带并显示组名。
- 多组同时可见只属于展示层。任意时刻仍只有一个 Coordinator 所有者、一个 AutoBurst OrderedPlan、一个 capture 和一个 Burst 候选；非活动组不得获得派发状态。
- 当前组“启用/停用”位于“当前组基本设置”上方；缺少窗口、缺少可选步骤或存在跨组冲突时仍 fail-closed。
- 顺序编辑器仍可操作九步，但下方饰品设置和滚动子页高度必须按当前实际条目数移动与收缩，不得留下固定 3200 像素尾部空白。
- 窗口 SpellID 数字输入、Enter/按钮保存以及同组周期刷新不覆盖输入的 `1.4.2` 行为保持不变。

## 协议与验证

- TEAP v3 仍为 20 字节，Burst flags 仍为 `0x20`；BindingToken、TEK 门禁、宏资格和脱战硬门控均未修改。
- 必须运行基线契约、完整 pytest、两套 unittest、compileall 和全部 AddOn Lua 语法检查。
- 实机需验证两到三个启用组同时显示、组顺序与组内顺序、横向/纵向布局、当前组开关位置，以及不同条目数量下滚动末端没有大段空白。
